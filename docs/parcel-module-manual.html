Transport ERP · Parcels Module

From setup to parcel handover.

This manual covers the whole module: what an administrator sets up once (prices, points, refunds, printing…) and what a counter clerk does every day, from drop-off to handover.

🇫🇷 The interface is in French. Explanations here are in English, but menu names, buttons and statuses are shown in their exact on-screen French text — like this: Nouveau colis — so you can find them on screen.

PART A

Setup (administrator)

Done once, before daily use. These settings decide prices, the points served, refunds and printing.

A1Module & access rights

Enable the module and grant rights

The Colis (Parcels) module is an option enabled per company (entitlement). Actions are then opened by role (RBAC): grant the right to the role, then the user must log out and back in for it to take effect.

RightAllows
ticketing.parcel.viewView the list, receiving and dispatch.
ticketing.parcel.manageRegister, ship, hand over, deliver, cancel.
ticketing.luggage.*Baggage (separate section, same principles).
Admin only. Removing a parcel already validated on a trip is reserved for the administrator — even for a counter clerk who holds the manage right.
A2Points & agencies

Departure and arrival points Configuration → Agences

Each agency is also a point on the network. The parcel's Point de départ (departure) and Point d'arrivée (arrival) fields are filled from these agencies. Create them before registering parcels.

A3Pricing — parcel types

Parcel types & pricing Configuration → Types de colis

The parcel type drives pricing. Each type has a code, a label, applies to Parcel / Baggage / Both, and can cap weight and volume. Pricing follows one of three rules:

Type settingEffect at drop-off
Fixed price setPrice is enforced — the clerk cannot change it.
Min / max price setThe clerk enters a price within the allowed range.
No price setFree entry of the amount.
Tip. Use a fixed price for regulated tariffs and a range for parcels priced by weight or negotiation.
A4Parcel natures

Natures (classification) Configuration → Natures de colis

Optional classification of a parcel by its nature, with flags: fragile, declaration required, prohibited. Optional for daily use — pricing goes through the parcel type (A3).

A5Payment methods

Payment methods Configuration → Modes de paiement

Define the methods offered at payment (cash, Mobile Money…). A method carries a "payment required" flag: a "no-payment" method records no income (useful for a drop-off settled another way).

A6Voyages settings (parcels)

Transport & pickup rules Configuration → Paramètres

One company-level setting block that affects parcels:

  • Partial pickup allowed — if on, a multi-piece parcel can be collected as soon as part of it arrives; otherwise it must fully arrive first. (On by default.)
  • Max parcel weight / trip (kg) and max parcel count / trip — a trip's loading limits.
  • Auto-print by default, SMS by default — defaults applied at registration.
A7Refunds

Refund policy on cancellation Trésorerie → Remboursement

For the "colis" (parcel) type, choose the method: percentage of the amount paid or a fixed amount (capped at what was collected).

Default: 0%. Until a parcel refund rate is configured, cancelling a parcel refunds nothing. When a refund applies, it is paid out from the agent's open cash drawer.
A8Documents & printing

Header/footer & printers Configuration → Modèles de documents

The document templates set the shared header and footer (receipt, label, manifest) — logo, company name, legal mentions. Printing is per workstation: each counter picks its printers under Configuration → Imprimantes (ce poste) (receipt, label). See the README-POSTE-CLIENT.txt guide.

A9Numbering

References & recovery after an outage Colis → Numérotation

Each parcel gets a monthly per-agency reference like DLA/0001/10/2026 (prefix / number / month / year). After an outage where parcels were logged on paper, the Numérotation button lets you set the next number to realign it — forward jump only, never a number already issued.

PART B

Operations (day to day)

A parcel's journey, screen by screen. Everything lives under the Colis menu.

A parcel's lifecycle
Enregistré→ Prêt à expédier→ En transit→ Arrivé→ Disponible pour retrait→ Retiré
Read as: Registered → Ready to ship → In transit → Arrived → Available for pickup → Collected. Cross-cutting statuses: Partiellement expédié (partly shipped) and Annulé (cancelled, before shipping).
The journey, step by step

Register a parcel & take payment

Colis → Nouveau colis
  • Route: departure point, arrival point.
  • Sender / Recipient: names and phones; the recipient's ID is optional at drop-off — it is checked at pickup.
  • Content: parcel type (sets the price — A3), quantity, declared value, weight.
  • Payment: payment method, amount received, change.

Confirm with Enregistrer & encaisser (Register & collect). The parcel starts Enregistré. Then print the Reçu (receipt) and Étiquette (label) from the row — printed on this workstation's printer.

Ship — assign to a trip

Colis → Expédition
  • 1. Choose the trip: filters for route, destination, trip day (Jour du voyage, defaults to today), vehicle / code.
  • 2. Load: Affecter (assign) parcels from "ready" to "on the trip" (partial quantity possible), then Expédier / Tout expédier (ship / ship all).
  • Print the Manifeste (trip manifest — list of parcels on board).
After validation, a counter clerk can no longer remove a parcel from the trip — only an administrator can.

Receive on arrival

Colis → Réception colis
  • Parcels in transit for the point appear here.
  • Enter Reçues (received), Manquant (missing), Avarié (damaged), then Réceptionner (receive) — or Réceptionner Tout (receive all).

The parcel becomes Disponible pour retrait. Only received parcels can be handed over or delivered.

Hand over to the recipient (pickup)

Colis → Retrait colis
  • By the recipient: check the ID (CNI) — mandatory.
  • By a proxy (mandataire): the proxy's name + ID (CNI), both mandatory.
  • Pieces to release: if partial pickup is allowed (A6), enter the number of pieces handed over.

Confirm with Valider le retrait (confirm pickup) → the parcel becomes Retiré.

Home delivery paid service

Colis → Livraison colis
  • For an arrived parcel: Livrer (deliver) → delivery address, amount, received by (name + ID).
  • The delivery income is recorded automatically.

Cancel a parcel

Colis → Tout Afficher → Annuler la sélection
  • Only while the parcel is Enregistré or Prêt à expédier.
  • Already on a trip? An administrator must remove it from the trip first.
  • Refund follows the A7 configuration (0% by default).
Where the money shows up

Trésorerie → Recette colis (parcel income) and Trésorerie → Recette livraison (home-delivery income). No double entry — income comes straight from the module's payments.

SymptomCause & fix

Nothing printsRun start-print-agent.bat; check http://localhost:9113/printers.

Cheat sheet — the daily routine
  1. Drop-off — Nouveau colis → fill in → Enregistrer & encaisser → print Reçu + Étiquette.
  2. Departure — Expédition → trip (destination + day) → Affecter → Expédier → Manifeste.
  3. Arrival — Réception colis → received / missing / damaged → Réceptionner.
  4. Handover — Retrait colis → check ID / CNI (or proxy) → Valider le retrait.
  5. Optional — Livraison colis → address + amount → Livrer.
