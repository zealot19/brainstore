Chapter 1

Getting started

The Brainstore Transport Package is a multi-company platform for running a passenger-transport business. Each company (institution) works in complete isolation from the others.

1.1 Who does what — the three roles

RolePurposeTypical tasks
Super AdminRuns the platformCreate institutions, manage packages & subscriptions, oversee agencies.
Institution AdminRuns one companyCreate agencies & users, configure journeys and fleet, define roles.
Agent / OperatorDay-to-day counter workSell tickets, register parcels/baggage, open a cash register, run trips.

1.2 Signing in

  1. Open the application URL in your browser.
  2. On the Sign In page, enter your email (or username) and password.
  3. Click Sign In. If you forgot your password, use Forgot Password?.
Note  What you see in the left menu depends on your permissions. If a module or button is missing, your role does not grant it — ask your Institution Admin.

1.3 Finding your way around

The left sidebar groups everything by module: Voyages Flotte Trésorerie Comptabilité Administration Reporting, plus Config Voyages for setup. Click a module to expand its sub-pages. Throughout this manual a path such as Trésorerie → Caisses means "open Trésorerie in the sidebar, then click Caisses".

Chapter 2

Administration

Administration is where the company, its agencies, its people and their access rights are defined. Do this first — everything else builds on it.

2.1 Creating an institution (Super Admin)

An institution is a company on the platform. Creating one automatically seeds its SYSCOHADA chart of accounts, journals, treasury mappings and default journey configuration — so it is ready to operate.

  1. Go to Super Admin → Institutions and click New institution.
  2. Fill in the identity: name, legal form, capital, RCCM, NIU/tax id, address, phone, currency, accounting plan.
  3. Optionally provide the first admin (email, first name, last name) — the platform creates the Institution Admin account.
  4. Save. The company is created and bootstrapped.

2.2 Creating agencies

An agency is a branch/office of your company (e.g. BAMENDA, BIYEM-ASSI). Cash registers and ticket-selling points attach to agencies.

  1. As Institution Admin, open Administration → Agences.
  2. Click Nouvelle agence, enter the name, code, type (Siège, Agence, Dépôt…), email and phone.
  3. Save. Repeat for each branch. You can nest agencies under a parent to model a hierarchy.

2.3 Creating users

  1. Open Administration → Utilisateurs and click New user.
  2. Enter identity and email; set the user's company and default agency.
  3. Save — the user receives credentials and can sign in.

2.4 Roles & permissions (RBAC)

Access is controlled by permissions (e.g. voyage.trip.create, treasury.session.manage). You bundle permissions into a role, then assign the role to a user. Institution Admins and Super Admins bypass these checks.

To grant an agent the right to sell tickets and run a caisse

  1. Go to Administration → Rôles and click New role (e.g. "Guichetier").
  2. Tick the permissions: ticketing/booking, treasury.session.view/manage, voyage.trip.view, etc.
  3. Save the role.
  4. Open the user, assign the role, and save. The agent now sees exactly those modules.
Scenario

Onboarding a new agency with one counter agent

Goal: open the BAMENDA agency and give agent Chantal the ability to sell tickets.

  1. Administration → Agences → Nouvelle agence → name "BAMENDA", code "BAM" → Save.
  2. Administration → Utilisateurs → create Chantal, company = your company, default agency = BAMENDA.
  3. Administration → Rôles → create "Guichetier" with ticketing + treasury.session + voyage.expense permissions.
  4. Assign "Guichetier" to Chantal. She can now open a caisse at BAMENDA and sell.
Chapter 3

Configuration

Configuration is the reference data journeys rely on: where you travel, at what price, in which seats, and what a trip costs. It lives under Config Voyages.

3.1 The building blocks

ItemWhat it is
Villes / Points de serviceTowns and their stations/agencies. A ticket-selling point is linked to an agency.
Trajets (Routes)An origin → destination line (e.g. Bamenda → Douala).
Catégories tarifaires (Fare Classes)Commercial tiers: CLASS, VIP, VIP PREM…
Plans de salle (Seating plans)Seat layout of a bus type; assigned to vehicles.
Types d'équipageCrew roles: Chauffeur, Convoyeur, Contrôleur… (a driver type is flagged "conducteur").
Types & natures de colisParcel categories used when registering colis/bagages.
Types de dépense & BarèmeExpense categories (Carburant, Péage, Ration…) and standard costs per route & class — see §3.3.

3.2 Creating a route

  1. Ensure the towns and their service points exist (Config Voyages → Points de service).
  2. Open Config Voyages → Trajets → Nouveau trajet.
  3. Pick the origine and destination stations, give it a code (e.g. BDA-DLA), optional distance/duration.
  4. Save. The route is now selectable when creating trips and fares.

3.3 Expense types & the barème (standard trip costs)

Define once, and every matching trip inherits its costs automatically.

Step A — expense types

  1. Open Config Voyages → Types de dépense → Nouveau type.
  2. Enter a name (e.g. Carburant) and pick its OHADA charge account from the dropdown (e.g. 604).
  3. Save. Repeat for Péage, Ration chauffeur, Ration convoyeur, Autres…

Step B — the barème

  1. Open Config Voyages → Barème dépenses → Nouveau barème.
  2. Choose the Trajet and the Catégorie tarifaire (e.g. Bamenda→Douala, VIP).
  3. Add lines: for each expense type, enter the standard amount (Carburant 40 000, Ration chauffeur 10 000, Péage 3 000…).
  4. Save. Every VIP trip created on that route will now start with these expenses pre-filled.
Scenario

Setting up a brand-new line

Goal: open the Bamenda → Douala VIP line with a fare and cost barème.

  1. Create the two stations under Points de service (Bamenda gare, Douala gare).
  2. Create the Trajet Bamenda → Douala.
  3. Create/confirm the VIP fare class and its fare (Config Voyages → Tarifs).
  4. Create the Barème for (Bamenda→Douala, VIP) with carburant/ration/péage lines.
Chapter 4

Fleet (Flotte)

The fleet module tracks your vehicles and everything they consume and cost: fuel, maintenance, insurance contracts, documents, missions and accidents.

4.1 Prepare the fleet reference data

Under Fleet configuration, define the reusable lists first: vehicle categories, fuel types, transmissions, brands & models, document types, tags, intervention types, suppliers and parkings.

4.2 Registering a vehicle

  1. Open Flotte → Véhicules → New vehicle.
  2. Select the model (brand/model), enter the licence plate, VIN, colour, year, category, and the owning agency.
  3. Optionally fill acquisition and fiscal values (purchase, catalogue, residual), tank capacity and current odometer.
  4. Save. The vehicle is Available and can be assigned to trips.

4.3 Recording fuel

  1. Open the vehicle (or Flotte → Carburant) and click New fuel log.
  2. Enter date, odometer at fill-up, litres, cost per litre (total is computed), station, and whether it was a full tank.
  3. Save. Fuel logs feed the vehicle's consumption & cost history.
Good to know  Fleet fuel logs are the actual fill-ups (litres, odometer). The "Carburant" line on a trip's expenses is a separate per-trip allowance — the two are intentionally kept apart.

4.4 Maintenance & contracts

  • Services / entretien — plan a service (intervention type, supplier, planned date). When done, record start/done dates, odometer and cost, plus the next due (km or date).
  • Contrats — insurance and other contracts: supplier, policy number, start/expiry dates, activation cost, deductible, billing period, plus recurring costs.
  • Documents — carte grise, assurance, visite technique… with issue/expiry dates for reminders.
  • Accidents — severity, at-fault, third party, police report, insurance claim, estimated vs actual repair cost.
Scenario

Putting a new bus into service

  1. Create the brand/model if new, then register the vehicle with its plate at your agency.
  2. Attach its documents (assurance, visite technique) with expiry dates.
  3. Log the first fuel fill-up and schedule the first maintenance with a next-due km.
  4. The bus now appears among eligible vehicles when you assign one to a trip.
Chapter 5

Journeys (Voyages)

A journey (trip) is one scheduled departure on a route. This chapter covers creating it, assigning a bus and crew, running its lifecycle, and recording its expenses.

5.1 Creating a trip

  1. Open Voyages → Voyages → New trip.
  2. Choose the trajet, the catégorie tarifaire, and the scheduled departure & arrival times.
  3. Save. The trip is created as a Draft. If a barème exists for (route, class), its expenses are copied in automatically.

5.2 Assigning a vehicle & crew

  1. Open the trip. Under Véhicule, pick an eligible bus and confirm — this generates the seat map from the bus's seating plan.
  2. Under Équipage, add crew members (at least one must be a driver). Select each member and click add.
  3. Optionally block seats you do not want sold (maintenance, reserved) under the seat grid.

5.3 The trip lifecycle

ActionMeaning & requirement
Soumettre (Submit)Draft → Pending. Requires a vehicle (with seat plan) and at least one driver.
Départ (Depart)Pending → Departed. Marks the bus as gone.
Compléter (Complete)Departed → Completed. The trip is finished.
Annuler / Suspendre / ReprendreCancel, temporarily suspend, or resume a trip.
Marquer en retardFlag a delay with a reason.
TransbordementMove passengers/parcels/baggage to another bus or trip (e.g. breakdown or overflow).

5.4 Trip expenses & disbursing from a caisse

On the trip's Dépenses card you see the inherited/added expenses (status Prévue). To pay one out:

  1. Add or adjust any expense lines while they are Prévue (choose the type and amount).
  2. In Caisse de décaissement, choose the open cash register the money leaves from.
  3. Click Décaisser on the line. The amount leaves that caisse, an OHADA entry is posted (debit the charge account, credit the caisse), and the line becomes Décaissée.
Requirement  You must have an open cash session to disburse. If the dropdown is empty, open your caisse first (see Chapter 9).
Scenario

Running the 08:00 Bamenda → Douala departure

  1. Create the trip (Bamenda→Douala, VIP, today 08:00). Its expenses pre-fill from the barème.
  2. Assign bus LT 762 MF and add the driver + convoyeur.
  3. Open your caisse; on the Dépenses card choose that caisse and Décaisser the carburant and rations.
  4. Sell tickets (Chapter 6), then Soumettre → Départ at departure time → Compléter on arrival.
Chapter 6

Reservations (Réservations)

Selling tickets at the counter. Each paid booking automatically records a treasury movement and an accounting entry.

6.1 Selling a ticket

  1. Make sure your cash session is open (Chapter 9) — cash sales require it.
  2. Open the sales/booking screen and pick the trip (departure) and seat(s).
  3. Enter the passenger (or select an existing one) and the fare class.
  4. Choose the payment method and the amount received; confirm. The ticket is issued and can be printed.
Behind the scenes  A cash sale posts an income movement in your caisse and an OHADA entry (debit 571 caisse, credit 706 ticket sales). Non-cash (transfer/mobile money) posts to the bank account.
Scenario

Two VIP tickets for tonight's departure

  1. Open your caisse for the day.
  2. Select the 20:00 Bamenda → Biyem-Assi VIP trip and pick two seats.
  3. Enter each passenger, confirm cash payment. Two tickets print; your caisse balance rises by the total.
Chapter 7

Parcels (Colis)

Registering, paying, tracking and delivering cargo sent between service points.

7.1 Registering a parcel

  1. Open Voyages → Colis → New parcel.
  2. Choose the point de départ and point d'arrivée (they must differ), the parcel type, description, weight and pieces.
  3. Enter the sender and recipient details (name, phone, recipient ID).
  4. Enter the amount due and the amount received / payment method; save. A reference (e.g. COL00042) is generated and the shipping fee is booked to treasury (account 707).

7.2 Tracking & delivery

  • Status flows: Enregistré → Chargé → Réceptionné → Livré (or Annulé).
  • When loaded onto a trip, link the trip; on arrival mark it Réceptionné.
  • To deliver: mark Livré, record who collected it and the ID they presented.
Scenario

Send a parcel from Bamenda to Douala

  1. Register the parcel (Bamenda → Douala), sender & recipient, amount 8 000, cash — fee posts to treasury.
  2. Load it on the departing trip (status Chargé).
  3. At Douala, mark Réceptionné; when the recipient collects it with ID, mark Livré.
Chapter 8

Baggage (Bagages)

Checking in a passenger's baggage on a known trip, charging any excess, and delivering it at destination.

8.1 Checking in baggage

  1. Open Voyages → Bagages → New baggage.
  2. Select the trip (the departure is known at check-in). Optionally link the passenger's ticket; otherwise enter the sender's identity.
  3. Enter the type, description, weight and number of items. The system computes any excess over the free allowance.
  4. Enter the fare and amount received / payment method; save. A tag (e.g. BAG00007) is generated and the fee is booked to treasury (account 706). Free baggage (0) generates no movement.

8.2 Delivery

Status flows Enregistré → Chargé → Retiré. To hand it over, mark Retiré and add a collection comment if needed.

Scenario

Excess baggage at check-in

  1. Open baggage check-in for the passenger's trip and link their ticket.
  2. Enter 30 kg — the system charges the excess over the free allowance.
  3. Collect the fee (cash) → it posts to your caisse; print the tag.
Chapter 9

Treasury (Trésorerie)

Cash registers, daily sessions, movements and transfers. Every sale (tickets, parcels, baggage) and every disbursed trip expense flows through here — and posts automatically to accounting.

9.1 Cash registers & the daily session

  1. Create a caisse under Trésorerie → Caisses (name it, attach it to an agency).
  2. Each day, open a session (Trésorerie → Sessions → Open session): pick the caisse and confirm the opening balance.
  3. Work through the day — sales and expenses move money in/out of this open session.
  4. At day's end, close the session: enter the counted balance. The system computes the expected balance and the écart (excédent/manquant).

9.2 Movements & transfers

  • Transactions — income/expense movements with a category; most are created automatically by sales & expenses, but you can add others.
  • Transferts — move money between caisses and bank accounts (posts a matching OD accounting entry).
  • Comptes bancaires — bank accounts used for non-cash receipts.
Automatic accounting  Opening/using a caisse never requires manual bookkeeping: each movement posts an OHADA entry, and closing differences post to écart accounts (658 shortfall / 758 surplus).
Scenario

A cashier's day

  1. Morning: open your caisse with the opening float.
  2. Day: sell tickets, register parcels/baggage, disburse trip expenses — all from this caisse.
  3. Evening: count the cash, close the session; the écart shows any surplus/shortfall.
  4. Run Journaux de vente in Reporting to review the session (see Chapter 11).
Chapter 10

Accounting (Comptabilité)

The SYSCOHADA-compliant ledger. Most entries are generated automatically from treasury; accountants can also post manual entries and review the books.

  • Plan comptable — the chart of accounts (class 5 treasury, class 6 charges, class 7 products…), seeded per company.
  • Journaux — sales, purchases, cash (CAISSE), bank (BANQUE), miscellaneous (OD).
  • Exercices & Périodes — fiscal years and periods; close a period when done.
  • Écritures — double-entry, gap-less numbering, immutable once posted, reversible by contre-passation.
Where entries come from  Ticket sales → 706, parcels → 707, baggage → 706, trip expenses → their configured charge account; each balanced against the caisse (571) or bank (521).
Chapter 11

Reporting

Generate branded statements as PDF, Excel or CSV, filtered by period, agency, caisse, vehicle or year.

11.1 Generating a report

  1. Open Reporting → Rapports.
  2. Choose the report from the list.
  3. Fill the filters shown for that report (dates, agency, caisse, vehicle, year).
  4. Pick the format (PDF / Excel / CSV) and click Générer — the file downloads.

11.2 Available reports

ReportWhat it shows
DépenseTrip expenses paid, by trip/vehicle/type and the caisse that paid.
RecetteTicket receipts grouped by caisse (and cashier).
CA (production)Turnover by agency × month.
RécapitulatifPer vehicle: revenue (voyage/bagage/colis) − expenses = margin.
Journaux de ventePer session: opening/expected/actual balance and écart.
VoyagesTrips with reservation & parcel totals.
Réservation / Bagages / ColisTransactional lists of tickets, baggage and parcels.
Scenario

End-of-day review for a manager

  1. Run Journaux de vente for today, filtered to the agency — check each caisse's écart.
  2. Run Recette for today to see receipts by cashier.
  3. Run Récapitulatif for the period to see each bus's margin (revenue − expenses).

Appendix

Glossary

TermMeaning
InstitutionA company on the platform (fully isolated from others).
AgenceA branch/office; caisses and selling points attach to it.
Caisse / SessionA cash register and its daily open/close cycle.
TrajetA route (origin → destination).
VoyageOne scheduled departure on a trajet.
BarèmeStandard trip costs per (route × fare class).
DécaisserPay an expense out of a chosen caisse.
ÉcartDifference between counted and expected cash at close (surplus/shortfall).
OHADA / SYSCOHADAThe West/Central-African accounting standard used by the ledger.

Everyday tips

  • Open your caisse before selling or disbursing — cash operations need an open session.
  • Configure the barème once per line so every trip inherits its costs.
  • If a menu/button is missing, it is a permission — ask your Institution Admin.
  • Reports are always available in PDF, Excel and CSV — use Excel/CSV for further analysis.
  • Keep vehicle documents up to date with expiry dates so nothing lapses.
