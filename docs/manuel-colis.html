ERP Transport · Module Colis

Du paramétrage à la remise du colis.

Ce manuel couvre tout le module : ce qu'un administrateur configure une fois (tarifs, points, remboursement, impression…) et ce qu'un guichetier fait chaque jour, du dépôt à la remise. Les libellés sont ceux affichés à l'écran.

Menu Colis Rôles Admin · Guichetier Droits ticketing.parcel.*
PARTIE A

Configuration (administrateur)

À régler une fois, avant l'usage quotidien. Elles décident des tarifs, des points desservis, des remboursements et de l'impression.

A1Module & droits d'accès

Activer le module et donner les droits

Le module Colis est une option activée par société (entitlement). Les actions sont ensuite ouvertes par rôle (RBAC) : attribuez le bon droit au rôle, puis l'utilisateur doit se reconnecter pour que le droit prenne effet.

DroitPermet
ticketing.parcel.viewConsulter la liste, la réception, l'expédition.
ticketing.parcel.manageEnregistrer, expédier, retirer, livrer, annuler.
ticketing.luggage.*Bagages (section autonome, mêmes principes).
Admin uniquement. Retirer un colis déjà validé sur un voyage est réservé à l'administrateur, même pour un guichetier qui a le droit manage.
A2Points & agences

Les points de départ et d'arrivée Configuration → Agences

Chaque agence est aussi un point du réseau. Les champs Point de départ et Point d'arrivée du colis se remplissent à partir de ces agences. Créez-les avant d'enregistrer des colis.

A3Tarifs — Types de colis

Types de colis & tarification Configuration → Types de colis

Le Type de colis est le cœur de la tarification. Chaque type a un code, un libellé, s'applique à Colis / Bagage / Les deux, et peut borner le poids et le volume. La tarification suit l'une de ces trois règles :

Réglage du typeEffet au dépôt
Prix fixe définiPrix imposé, non modifiable par le guichetier.
Prix min / max définisLe guichetier saisit un prix dans la fourchette autorisée.
Aucun prixSaisie libre du montant.
Astuce. Utilisez un prix fixe pour les tarifs réglementés et une fourchette pour les colis facturés au poids/à la négociation.
A4Natures de colis

Natures (classification) Configuration → Natures de colis

Classification optionnelle d'un colis par sa nature, avec des indicateurs : fragile, déclaration requise, interdit. Facultatif pour l'usage courant — la tarification passe par le Type de colis (A3).

A5Modes de paiement

Modes de paiement Configuration → Modes de paiement

Définissez les modes proposés à l'encaissement (espèces, Mobile Money…). Un mode porte un indicateur « encaissement requis » : un mode « sans paiement » n'enregistre aucune recette (utile pour un dépôt pris en charge autrement).

A6Paramètres Voyages (colis)

Règles de transport & retrait Configuration → Paramètres

Un réglage par société qui influence les colis :

  • Retrait partiel autorisé — si activé, un colis de plusieurs pièces est retirable dès qu'une partie est arrivée ; sinon il faut l'arrivée complète. (Activé par défaut.)
  • Capacité colis max / voyage (kg) et Nombre max de colis / voyage — limites de chargement d'un voyage.
  • Impression auto par défaut, SMS par défaut — comportements par défaut à l'enregistrement.
A7Remboursement

Politique de remboursement à l'annulation Trésorerie → Remboursement

Pour le type « colis », choisissez la méthode : pourcentage du montant payé ou montant fixe (plafonné au montant encaissé).

Par défaut : 0 %. Tant qu'aucun taux n'est configuré pour les colis, annuler un colis ne rembourse rien. S'il y a remboursement, il est décaissé depuis la caisse ouverte de l'agent.
A8Documents & impression

En-tête/pied & imprimantes Configuration → Modèles de documents

Les Modèles de documents fixent l'en-tête et le pied communs (reçu, étiquette, manifeste) — logo, raison sociale, mentions légales. L'impression se fait poste par poste : chaque guichet choisit ses imprimantes dans Configuration → Imprimantes (ce poste) (reçu, étiquette). Voir le guide README-POSTE-CLIENT.txt.

A9Numérotation

Références & reprise après coupure Colis → Numérotation

Chaque colis reçoit une référence mensuelle par agence, type DLA/0001/10/2026 (préfixe / numéro / mois / année). Après une coupure où les colis ont été notés sur papier, le bouton Numérotation permet de fixer le prochain numéro pour le réaligner — saut en avant uniquement, jamais un numéro déjà émis.

PARTIE B

Opérations (au quotidien)

Le parcours d'un colis, écran par écran. Tout se trouve dans le menu Colis.

Cycle de vie d'un colis
Enregistré→ Prêt à expédier→ En transit→ Arrivé→ Disponible pour retrait→ Retiré
Statuts transverses : Partiellement expédié quand une partie des pièces est partie, et Annulé avant expédition.
Le parcours, étape par étape

Enregistrer un colis & encaisser

Colis → Nouveau colis
  • Trajet : Point de départ, Point d'arrivée.
  • Expéditeur / Destinataire : noms et téléphones ; la Pièce du destinataire est facultative au dépôt — elle sera vérifiée au retrait.
  • Contenu : Type de colis (fixe le tarif — A3), Quantité, Valeur déclarée, Poids.
  • Encaissement : Mode de paiement, Encaissé, Monnaie rendue.

Validez par « Enregistrer & encaisser ». Le colis part Enregistré. Imprimez ensuite le Reçu et l'Étiquette (icônes de la ligne, impression sur l'imprimante de ce poste).

Expédier — affecter à un voyage

Colis → Expédition
  • 1. Choisir le voyage : filtres Trajet, Destination, Jour du voyage (par défaut aujourd'hui), Véhicule / Code.
  • 2. Charger : Affecter les colis de « Colis prêts » vers « Colis du voyage » (quantité partielle possible), puis Expédier / Tout expédier.
  • Imprimez le Manifeste du voyage (liste des colis à bord).
Après validation, un guichetier ne peut plus retirer un colis du voyage — seul un administrateur le peut.

Réceptionner à l'arrivée

Colis → Réception colis
  • Les colis En transit du point apparaissent.
  • Saisissez Reçues, Manquant, Avarié, puis Réceptionner (ou Réceptionner Tout).

Le colis devient Disponible pour retrait. Seuls les colis réceptionnés peuvent être retirés ou livrés.

Remettre au destinataire (Retrait)

Colis → Retrait colis
  • Par le destinataire : vérifier la Pièce (CNI) — obligatoire.
  • Par un mandataire : Nom + Pièce (CNI) du mandataire, obligatoires.
  • Pièces à retirer : si le retrait partiel est autorisé (A6), indiquer le nombre de pièces remises.

Confirmez par « Valider le retrait » → le colis passe Retiré.

Livrer à domicile service payant

Colis → Livraison colis
  • Pour un colis arrivé : Livrer → Adresse de livraison, Montant, Reçu par (nom + pièce).
  • La recette de livraison est enregistrée automatiquement.

Annuler un colis

Colis → Tout Afficher → Annuler la sélection
  • Possible uniquement tant que le colis est Enregistré ou Prêt à expédier.
  • Déjà sur un voyage ? Un administrateur doit d'abord le retirer du voyage.
  • Remboursement selon la configuration A7 (0 % par défaut).
Où voir l'argent encaissé

Trésorerie → Recette colis (dépôts) et Trésorerie → Recette livraison (livraisons à domicile). Aucune double saisie : les recettes proviennent des encaissements du module.

Aide-mémoire — le geste de tous les jours
  1. Dépôt — Nouveau colis → remplir → Enregistrer & encaisser → imprimer Reçu + Étiquette.
  2. Départ — Expédition → voyage (Destination + Jour) → Affecter → Expédier → Manifeste.
  3. Arrivée — Réception colis → Reçues / Manquant / Avarié → Réceptionner.
  4. Remise — Retrait colis → vérifier la CNI (ou mandataire) → Valider le retrait.
  5. Option — Livraison colis → adresse + montant → Livrer.
